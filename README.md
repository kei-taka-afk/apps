# apps

Study apps, served with GitHub Pages: https://kei-taka-afk.github.io/apps/

- Each folder is one app (plain HTML / JavaScript, no build step). `index.html` at the top is the list.
- `records/<app>/` holds learning records exported from the Claude account on 2026-11-26 (raw JSON, plus `progress.csv` where the format is known).
- `.nojekyll` tells GitHub Pages to serve the files as they are.

Apps: english-idioms, eiken1-vocabulary, english-vowels, english-grammar, eibunpo-drill, english-beginner, gmat-drill, korean-sentences, hangul-typing, topik-drill, boki2-drill, fp-drill, cma-drill, fe-drill, genai-passport-drill, ccar-f-drill, color-exam-drill, personal-color-drill, piano-practice, ear-training, holy-bible, iching, kyo-no-itte
